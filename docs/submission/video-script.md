# Video script — Ashfield (NASA Space Apps 2026)

Target: **2–3 minutes**, for the jury. Built around the Mendoza demo — a fictional producer with a vineyard-and-grains farm in the Uco Valley (task 40 demo farm). Spanish narration is the cut to record; the English version follows.

> Note: the demo farm label may read "Ver un ejemplo" or the farm's own name once task 40 lands — check the welcome screen on recording day and adjust the click path below.
